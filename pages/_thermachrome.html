      Warming in Colour

      Data & Method

      Data sources

      All data is served by the Open-Meteo Archive API (free, no API key). Four reanalysis datasets are available:

      Source Grid Period Coverage
      ERA5-Land~11 km1950–nowGlobal
      ERA5~25 km1940–nowGlobal
      CERRA~5 km1985–2021Europe only
      ECMWF IFS~9 km2017–nowGlobal

      ERA5 and ERA5-Land are produced by ECMWF and updated daily with a ~5-day lag. CERRA is a regional reanalysis for Europe with the finest spatial resolution — recommended for Italian cities. ECMWF IFS covers only recent years but at high resolution.

      Anomaly calculation

      For each stripe, the anomaly is the departure of that period's mean temperature from the 1961–1990 WMO standard climate normal — the reference period recommended by the World Meteorological Organization and used by Copernicus/ECMWF. The comparison is always like-for-like: a July stripe is compared to the average July of 1961–1990, a Monday week-stripe to the average of the same ISO week across 1961–1990, and so on. Colour intensity is scaled to ±3 standard deviations of the baseline distribution.

      Period means

      Each stripe value is the arithmetic mean of all valid daily readings within the chosen granularity window — a calendar day, ISO week, calendar month, or calendar year. Days with missing ERA5 values are excluded from the average.

      Absolute colour scale

      When Absolute colouring is selected, Mean uses the full RdBu palette mapped linearly from the coldest to the warmest value in the current dataset. Max and Min use fixed half-palettes instead — Max ranges white (0°C) to dark red (40°C), Min ranges dark blue (−20°C) to white (0°C) — so a mild 12°C reading is never mistaken for deep cold.

      Design inspiration

      The visual concept and interaction design of this viewer is inspired by Living Warming Stripes, created by Alejandro Quinto Fernández (LinkedIn). This is an independent re-creation built for EETRA srl SB, extended with local Italian ERA5 station data, multi-city comparison, and a classic bar-chart view.
